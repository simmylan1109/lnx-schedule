## 走查中确认的两件事(不是 bug)

- 导入的全天事件显示 "Jan 1":走查手工构造的备份文件把全天字段写成了 epochDay,
  而格式规范是 epoch millis —— **文件写错,App 按规范解析无误**(M7 时期的真实备份
  导入回归见既有测试)。
- 手机上装的旧 0.2.0 覆盖升级会保留数据(签名一致 versionCode 递增);
  调试包签名不同,不能覆盖(昨天模拟器实测过该报错)。
